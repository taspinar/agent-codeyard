New to coding agents, pull requests or independent reviews? Read <a href={href("docs/new-to-agentic-coding/")}>New to agentic coding? Start here</a> first. If you already work with a coding agent, start with <a href={href("docs/getting-started/")}>Getting started</a>. <a href={href("docs/detailed-workflow/")}>How the workflow works</a> explains the route and its choices; the <a href={href("docs/reference/workflow/")}>workflow reference</a> lists the command, the inputs and outputs and the stop conditions of every step. The sidebar covers configuration, risk policy, GitHub settings and recovery.

The workflow runs on your machine. As shipped, Claude implements and Codex reviews, so install both providers. You approve planning and merge pull requests; no script merges for you. Under the shipped policy every feature is reviewed. A project can explicitly allow Low features to skip review; their merge then needs the owner.

A project starts from the template, or an existing repository adopts the workflow: <a href={href("docs/adopting/")}>Adopting Codeyard in an existing repository</a>. <a href={href("docs/updating/")}>Updating a Codeyard-based project</a> covers taking over later template changes.

## Find a command or setting

Search matches words in the built pages, including code and tables. It runs entirely in your browser, with a static index and no external service. Without JavaScript, every page remains available through the sidebar and its table of contents.

## Sources and scope

The site describes the current template. Your repository's [development guide](https://github.com/taspinar/agent-codeyard/blob/main/docs/development.md), [workflow reference](https://github.com/taspinar/agent-codeyard/blob/main/docs/workflow.md) and [repository setup guide](https://github.com/taspinar/agent-codeyard/blob/main/docs/repository-setup.md) describe the version installed in your project.

The <a href={href("docs/technical-reference/")}>technical reference</a> links scripts and configuration to their source. History, research and possible improvements belong to <a href={href("about/")}>About</a>.

Two routes into Agent Codeyard, depending on where you start:

- **A new project:** <a href={href("docs/getting-started/")}>Getting started</a> creates the repository with `gh repo create --template`, plans it with you and runs the first feature.
- **An existing repository:** <a href={href("docs/adopting/")}>Adopting Agent Codeyard in an existing repository</a> assesses it, adds the workflow on a branch you review and records what already fails.

New to coding agents, pull requests or independent reviews? Read <a href={href("docs/new-to-agentic-coding/")}>New to agentic coding? Start here</a> first. Short answers, such as the cost or the supported environments, are in the <a href={href("faq/")}>FAQ</a>. <a href={href("docs/detailed-workflow/")}>How the workflow works</a> explains the route and its choices; the <a href={href("docs/reference/workflow/")}>workflow reference</a> lists the command, the inputs and outputs and the stop conditions of every step. The sidebar covers configuration, risk policy, GitHub settings and recovery.

The workflow runs on your machine. As shipped, Claude implements and Codex reviews, so install both providers. You approve planning and merge pull requests; no script merges for you. Under the shipped policy every feature is reviewed. A project can explicitly allow Low features to skip review; their merge then needs the owner. <a href={href("docs/updating/")}>Updating an Agent Codeyard project</a> covers taking over later changes of Codeyard.

## Sources and scope

The site describes the current version of Codeyard. Your repository's [development guide](https://github.com/taspinar/agent-codeyard/blob/main/docs/development.md), [workflow reference](https://github.com/taspinar/agent-codeyard/blob/main/docs/workflow.md) and [repository setup guide](https://github.com/taspinar/agent-codeyard/blob/main/docs/repository-setup.md) describe the version installed in your project.

The <a href={href("docs/technical-reference/")}>technical reference</a> links scripts and configuration to their source. <a href={href("docs/history/")}>History and research</a> follows how Codeyard evolved; the possible improvements belong to <a href={href("about/")}>About</a>.
